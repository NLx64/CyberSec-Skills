# Skills Directory

This directory contains all available Agent Skills organized by category.

## Categories

| Directory | Description |
|-----------|-------------|
| `incident-response/` | Skills for incident handling and response |
| `malware-analysis/` | Skills for analyzing malware and threats |
| `document-analysis/` | Skills for triaging suspicious documents |

## Adding a New Skill

1. Choose the appropriate category directory
2. Create a new directory with your skill name
3. Add a `SKILL.md` file following the standard format
4. Update this index if needed

See [CONTRIBUTING.md](../docs/CONTRIBUTING.md) for detailed guidelines.
