# Initial Incident Intake

> 🚧 **Coming Soon** - This skill is under development

## Overview

This skill standardizes the first-hour incident response procedures, helping analysts quickly scope incidents and prioritize actions.

## Planned Features

- **Structured Intake**: Consistent incident summary format
- **Evidence Requests**: Prioritized list of artifacts to collect
- **Working Hypothesis**: Initial assessment based on available information
- **Time Windows**: Identify critical timeframes for investigation
- **Containment Actions**: Recommended immediate response steps

## Inputs

- Freeform intake notes
- Environmental context (network topology, asset inventory)
- Initial alert data

## Outputs

- Scoped incident summary
- Evidence request lists
- Actionable next steps
- Known/Unknown assessment
